# Roadmap

Urutan milestone. Satu milestone = satu plan di `docs/plan/`.
Jangan mengerjakan milestone berikutnya sebelum milestone sebelumnya
lolos checklist code-review.

| Milestone | Isi | Status |
|-----------|-----|--------|
| m0-bootstrap | Kerangka proyek: Gradle, manifest, 1 Activity kosong yang jalan | Selesai (starter kit ini) |
| m1-foundation | UI dasar + resources (strings, colors, themes, layout utama) | Selesai (aplikasi starter 1 layar) |
| m2-main-feature | Fitur utama + validasi berlapis + (bila perlu) layar kedua | Template siap, isi sesuai proyek |
| m3-... | [ISI milestone berikutnya] | Belum dimulai |

## Aturan roadmap

- Milestone kecil lebih baik daripada milestone besar yang tidak selesai.
- Kalau satu milestone ternyata butuh 2 plan, pecah menjadi
  m2a dan m2b — jangan memperbesar plan sampai tidak bisa direview.
